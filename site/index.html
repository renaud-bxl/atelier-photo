Dépôt de publication à configurer

MAC / 01

Votre atelier sur Mac.

Apple Silicon ou Intel. L’installateur choisira l’archive de votre architecture et vérifiera son empreinte SHA-256.

En attendant la publication, ouvrez le dossier du projet dans Terminal. Node.js 24 et npm sont nécessaires.

Terminal
npm ci --include=optional
npm start
WINDOWS / 02

Votre atelier sur Windows.

Version x64. L’installateur utilise une archive ZIP portable, vérifie SHA-256 et l’installe dans votre dossier utilisateur.

En attendant la publication, ouvrez le dossier du projet dans PowerShell. Node.js 24 et npm sont nécessaires.

PowerShell
npm ci --include=optional
npm start
LINUX / 03

Votre atelier sur Linux.

Version x64 au format AppImage. Le téléchargement est vérifié avec SHA-256 et installé sans droits administrateur.

En attendant la publication, ouvrez le dossier du projet dans votre terminal. Node.js 24 et npm sont nécessaires.

Terminal
npm ci --include=optional
npm start

Lancez la seconde commande après la réussite de la première. Les versions Windows et Linux n’ont pas encore été validées sur leurs systèmes respectifs.
